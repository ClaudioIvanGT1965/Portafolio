SERVICIOS

Soluciones de software con visión de negocio y experiencia en distintas generaciones tecnológicas.

Soy Claudio Gutiérrez, analista y desarrollador de software. Acompaño proyectos desde el levantamiento de requisitos y el modelado de datos hasta la construcción de aplicaciones, integración de sistemas y evolución de plataformas existentes.

Análisis de negocio y requisitos

Identificación de necesidades, levantamiento de procesos, definición de reglas de negocio y especificación de requisitos funcionales para traducir problemas operativos en soluciones implementables.

Desarrollo de aplicaciones

Construcción y evolución de soluciones con .NET Framework, .NET 8 y Java/JEE. Aplicación de programación orientada a objetos, patrones de diseño y arquitecturas monolíticas, en capas y de microservicios, según el contexto del proyecto.

Bases de datos y persistencia

Análisis, modelado y programación de bases de datos relacionales con SQL Server, Informix, Oracle, MySQL y Access. Diseño de estructuras de información y consultas para respaldar procesos de negocio.

Aplicaciones web e integración

Desarrollo de interfaces y funcionalidades web con HTML, CSS3, JavaScript y jQuery; servicios con Node.js y soluciones Java con Spring. Experiencia complementaria con componentes DevExpress.
